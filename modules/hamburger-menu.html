Hamburger menu

mixed support
Interactive module · reference sheet

The three-horizontal-line navigation menu, by now standard on responsive websites, applied to email: on small screens the desktop menu collapses into an icon that expands on tap, so it doesn't take up precious space above the fold.

When to propose it: emails with an articulated navigation (several categories/sections) that needs to stay readable on mobile too, without weighing down the header.

Fallback: where the CSS3 trick isn't supported, the desktop menu simply stays fully visible and static, without collapsing.

Additional notes

Integration requirements, taken from the internal component library — available in two variants: desktop that turns into a hamburger on mobile, or mobile-only.

  • Default component width: 600px — the HTML width attribute and the inline style value must be identical; always keep the px unit in inline styles.
  • Default image width/height 600×400px, adjustable but must stay consistent across all images.
  • The <style> block must be copied into the email's <head>; the HTML must sit in a dedicated section of the body, without nesting it inside existing tables.
