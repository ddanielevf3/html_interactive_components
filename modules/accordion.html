Accordion / tab

mixed support
Interactive module · reference sheet

Sections that expand on tap/click (accordion) or content that alternates between panels (tab), built with the CSS3 checkbox/radio trick or, alternatively, with AMP for Email. Useful for compressing a lot of content — FAQs, sizes, ingredients — without stretching out the email, especially on mobile.

When to propose it: information-dense emails (product cards, newsletters with several articles) where you want to give a choice without saturating the space. Only works with clients that read external/embedded CSS: not with the Gmail app, nor with other third-party apps.

Fallback: where CSS3 isn't supported (Outlook, Gmail), the entire accordion content is shown in full, as a static version.

Additional notes

Integration requirements, taken from the internal component library — apply to both available variants (Simple and Advanced).

  • Default component width: 600px — the HTML width attribute and the inline style value must be identical; always keep the px unit in inline styles.
  • Advanced version: default image width/height 600×400px, customisable but must stay consistent across all images in the component.
  • The <style> block must be copied into the email's <head>; the HTML markup goes in the body without nesting it inside existing tables — it must sit in a dedicated section of the template.
