Form / AMP for Email

some clients only
Interactive module · reference sheet

Surveys, RSVPs or live prices that can be filled in/updated without leaving the email, using the AMP for Email standard. Only works on Gmail and Yahoo Mail: the specification requires a static HTML fallback version, which is therefore always needed and not optional.

When to propose it: only if the audience is strongly weighted towards Gmail/Yahoo and there's willingness to take on a project with higher development costs.

Fallback: mandatory under the AMP specification — a static HTML version of the email, with the same content and a link to an external page for the action (form, survey) that AMP would have handled in-email.

supportedGmail (AMP for Email), Yahoo Mail (AMP for Email)
fallbackevery other client — Outlook Windows/Mac, Apple Mail, Outlook.com, Office 365, Google Apps, AOL — only show the HTML fallback version
