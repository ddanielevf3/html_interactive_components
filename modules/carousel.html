Carousel / slider

mixed support
Interactive module · reference sheet

Rotates several images or slides inside a single block, typically via pure CSS (no JavaScript: emails don't execute it). Great for showing more products in the space of a single banner — different angles of a product, photos from an event, several articles inside a single hero image.

When to propose it: an opening hero with 2-4 products, editorial content with several visuals to cycle through. On mobile, always keep the landscape format: forcing portrait needs too much extra code and puts the email's deliverability at risk.

Fallback: a single static image summarising the carousel's content (not a GIF, which only a few clients support) — if none is specified, the client automatically shows the first slide.

Additional notes

Per-variant technical requirements, taken from the internal component library.

Image dimensions (all variants): 600px wide, retina (x2) at 1200px. Height is flexible.

With navigation arrows
  • 3, 4 or 6 images in retina (x2) format
  • 2 navigation icons in retina (x2) format
  • 1 fallback image in retina (x2) format
With arrows and dots
  • Same requirements as the arrows version — the dots are handled purely via CSS, with no extra assets
Outlook.com
  • 3, 4 or 6 images in retina (x2) format
  • 1 fallback image in retina (x2) format — no navigation icon required
With thumbnails (static or animated)
  • 3, 4 or 6 images in retina (x2) format
  • 3, 4 or 6 thumbnails in retina (x2) format — matching the number of images
  • 1 fallback image in retina (x2) format — the thumbnails themselves act as navigation
Simple Slide (pure CSS transition)
  • 3, 4 or 6 images in retina (x2) format
  • 1 fallback image in retina (x2) format
  • Active only on WebKit-based clients: iOS Mail, Apple Mail, Outlook for iOS and Mac
