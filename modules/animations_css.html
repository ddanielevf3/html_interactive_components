CSS Animations (hover & flip)

limited support
Interactive module · reference sheet

The CSS animation property applied to individual elements (images, spans, divs) — spinning icons, micro-animations on a call to action, an image swap on mouse hover, a "card flip" effect. No JavaScript needed (which isn't executed in emails anyway): it's just CSS/HTML already present in the template, so it works as a pure enhancement for whoever supports it.

Careful: hover doesn't exist on touch — on smartphones and tablets (the majority of email opens) an effect tied only to hover never triggers. Use it only for predominantly desktop campaigns (B2B, internal newsletters), never as the central effect for a consumer audience.

Fallback: as with the accordion, where it isn't supported the whole animation is simply shown as static content.

Additional notes

Integration requirements, taken from the internal component library.

  • The <style> block must be copied into the email's <head>; the HTML goes in a dedicated section of the body, without nesting it inside existing tables.
  • Before applying an effect, check whether the element (text or image) already has a class attribute: two classes on the same element cause conflicts. If it doesn't have one, create it and add the animation class, without the leading dot.
